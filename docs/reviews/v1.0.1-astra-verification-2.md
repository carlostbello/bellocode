## Outstanding blockers

- **AF06 — An older Apple Git can push to a destination outside the approval.** BelloCode accepts the installed CLT Git without a capability check. Apple Git-146 appends empty push-URL settings to the existing list, while BelloCode relies on them clearing the list. If the remote's explicit push URL changes after the last comparison, that Git visits the unapproved destination first. A second writable project on the same GitLab installation can receive the commit even if the overall push reports failure. Require proven reset semantics or bind the destination independently of that list.
