## New findings

### AV01 · blocker · Rotating a placeholder can return its new value to the agent

P5 reauthorizes after the upstream connection opens and rebuilds the request with the latest value. The response filter still takes its values from the snapshot captured before connecting. Rotation deliberately keeps the placeholder and binding. If the destination echoes the submitted value in an ordinary response or diagnostic, the new value reaches the agent in clear text. [EgressProxy.swift:605](../../Sources/SecretKit/EgressProxy.swift#L605) · [EgressProxy.swift:667](../../Sources/SecretKit/EgressProxy.swift#L667) · [EgressProxy.swift:774](../../Sources/SecretKit/EgressProxy.swift#L774) · [SecretManager.swift:654](../../Sources/Engine/Secrets/SecretManager.swift#L654)

The echo test keeps one value throughout. The gated test revokes the grant. Use one immutable dispatch snapshot for the transmitted value and its response scanner, and cover rotation during that gate with a reflecting origin. [ProxyTests.swift:70](../../Tests/SecretKitTests/ProxyTests.swift#L70) · [ProxyTests.swift:94](../../Tests/SecretKitTests/ProxyTests.swift#L94)

### AV02 · blocker · Transfer-compressed responses bypass placeholder redaction

The egress response reader accepts stacked transfer codings ending in chunked framing, but removes only the chunk framing. The filter decodes `Content-Encoding`, drops `Transfer-Encoding`, and scans the remaining bytes. A bound origin’s transfer-compressed echo can therefore reach the caller as recoverable compressed data containing the submitted value. [WireConnection.swift:209](../../Sources/SecretKit/WireConnection.swift#L209) · [WireConnection.swift:232](../../Sources/SecretKit/WireConnection.swift#L232) · [ResponseFilter.swift:150](../../Sources/SecretKit/ResponseFilter.swift#L150) · [ResponseFilter.swift:161](../../Sources/SecretKit/ResponseFilter.swift#L161) · [ResponseFilter.swift:182](../../Sources/SecretKit/ResponseFilter.swift#L182)

The encoding matrix exercises compression as content encoding and chunking separately. Reject unsupported transfer codings on inspected responses before returning any headers or body, or decode every supported layer under the inspection limit. [ProxyTests.swift:80](../../Tests/SecretKitTests/ProxyTests.swift#L80) · [TestServers.swift:92](../../Tests/SecretKitTests/TestServers.swift#L92)

### AV03 · blocker · A directory symlink named `.git` grants write access to another checkout’s metadata

The writable-root discovery uses a directory predicate that follows symlinks, then returns the canonical target of `.git`. A different repository’s real `.git` directory passes the name check and becomes a sandbox write root. Staging a file in the selected checkout can consequently change the other repository’s real index, even when that repository is outside the authorized roots. ### AV06 · blocker · The dev-container build can read its Dockerfile from outside the project

The recipe still uses an absolute pathname. Containment is checked, the name is resolved again, and `open` protects only the final component.
