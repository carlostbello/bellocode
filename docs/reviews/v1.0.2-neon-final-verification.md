## 1. Blocker

### NV3-01 · Crash (`SIGTRAP`) when closing a window while a new-thread draft's first send is creating its thread

- **Severity:** Blocker (app crash reachable in ordinary use)
- **Location:** [WorkspaceController.swift:185](../../Sources/BelloCodeApp/Shell/WorkspaceController.swift#L185)
- **Trigger path:**
  1. Open a new-thread draft (`⌘N`, or a project still cloning via **Clone from GitLab…**, or a draft with **Choose Workspace… ▸ New worktree**).
  2. Type a prompt and press Return (Send). `ComposerController.submit` ([ComposerController.swift:510–511](../../Sources/ComposerKit/Host/ComposerController.swift#L510-L511)) starts an unstructured `Task` retaining `DraftComposerHost` ([ComposerSurface.swift:375](../../Sources/BelloCodeApp/Content/ComposerSurface.swift#L375)) and its `ThreadSurfaceContext` ([Seams.swift:138](../../Sources/BelloCodeApp/Shell/Seams.swift#L138)).
  3. `DraftComposerHost.send` ([ComposerSurface.swift:427–445](../../Sources/BelloCodeApp/Content/ComposerSurface.swift#L427-L445)) suspends across `await job.waitUntilDone()` (if cloning), `await prepareDirectory(submission.text)` (if creating a worktree), and `await context.createThread(options)` → `await engine.createThread(...)` ([Seams.swift:237–239](../../Sources/BelloCodeApp/Shell/Seams.swift#L237-L239)).
  4. While any of those awaits is in flight, close the window (`⌘W` or close button). BelloCode stays running with no window open (`applicationShouldTerminateAfterLastWindowClosed` returns `false`, [AppDelegate.swift:111–114](../../Sources/BelloCodeApp/Launch/AppDelegate.swift#L111-L114)), and `MainWindows.closed(_:)` ([MainWindows.swift:109–116](../../Sources/BelloCodeApp/Launch/MainWindows.swift#L109-L116)) removes `MainWindowController` from `controllers` and calls `controller.workspace.close()`, unreferencing `WorkspaceController` so it deallocates.
  5. When `engine.createThread(...)` returns, `ThreadSurfaceContext.createThread` calls `openThread?(session.id)` ([Seams.swift:239](../../Sources/BelloCodeApp/Shell/Seams.swift#L239)), which executes [WorkspaceController.swift:185](../../Sources/BelloCodeApp/Shell/WorkspaceController.swift#L185):
     ```swift
     context.openThread = { [weak self] id in self?.threadModel(id) ?? self!.engine.openThread(id) }
     ```
  6. Because `threadModel(_:)` returns a non-optional `ThreadModel`, `self?.threadModel(id)` evaluates to `nil` **if and only if `self == nil`**. The `??` fallback `self!.engine.openThread(id)` then unconditionally force-unwraps `nil`, terminating the entire app (`SIGTRAP`) along with any other open windows and active work.
- **Fix direction:** Capture `engine` directly (never `self!`) and balance the temporary `ThreadModel` lease when the originating window is gone so `DraftComposerHost.send` can still deliver the first prompt without leaking an unclosed lease.
