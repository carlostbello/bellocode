## 2. New Blockers in Round-3 Diffs (R3a, R3b, R3c, `4c8c5c5`)

**None (0 blockers).**

Reviewed all core user flows across the round-3 diffs:
- **Sending messages & composer drafts (R3a `65e25c8`):** `placeRewoundPrompt` ([MainWindowController+Git.swift:422–441](../../Sources/BelloCodeApp/Shell/MainWindowController+Git.swift#L422-L441)) and `ComposerController.placeRecovered` / `adoptRecovered` ([ComposerController.swift:105–134, 352–361](../../Sources/ComposerKit/Host/ComposerController.swift#L105-L134)) deliver rewound prompts to every live composer of the thread across windows, wait for unloaded drafts before merging (falling back to `thread.draft` only on timeout), and preserve tokens and attachments via `ComposerDraft.merging` and `ShellSurfaces.draftHost`. No data loss or overwrite path found.
- **Auto approvals (R3a `7974d8d`, `84b6543`):** `OptionSyntax` ([OptionSyntax.swift](../../Sources/Engine/Auto/OptionSyntax.swift)) and `RiskPolicy` (`bellocode-auto-5`, [RiskPolicy.swift](../../Sources/Engine/Auto/RiskPolicy.swift)) bound `GrepSearch.readings` at 64 readings, preserve exact-option exemptions (`--text`, `--filter`, `--head`), and keep routine read-only commands (`git status`, `git diff`, `git log`, `git branch`/`tag`/`remote` listing forms, `git stash list`/`show`, non-recursive `grep`/`diff`) deterministically allowed while applying the intended stricter checks to option abbreviations, plain `git stash`, non-listing `git branch`/`tag`/`remote`, and `diff -r` / `git diff --no-index` / `git grep --no-index`/`--untracked`.
- **Rewinding (R3b `47b3ad5`):** `Engine.rewoundTurnsStart` ([Engine+GitParity.swift:103–126](../../Sources/Engine/Presentation/Engine+GitParity.swift#L103-L126)) pages messages in descending order (passing `order: .descending` on page 0 and only `cursor` thereafter, matching `MessageListQuery`'s contract), uses strict `session.created > rewoundSince` on the server's clock, and fails closed (`nil`) when history is unavailable.
- **Committing and pushing (R3b `9996389`, `be60d83`):** `HostGit.gitDirectories` ([HostGit.swift:80–181](../../Sources/ContainerKit/HostGit/HostGit.swift#L80-L181)) uses fd-bound `openat`/`F_GETPATH`/device+inode checks without breaking ordinary repos, linked worktrees, or submodules. `GitRepository.requirePinnablePush` and `GitPushPinning` ([GitWorkflows.swift:224–239, 588–627](../../Sources/Engine/Git/GitWorkflows.swift#L224-L239)) enforce git ≥ 2.46 / Apple Git-155 via version check plus behavioural `git remote -v` probe (verified locally against `git version 2.54.0 (Apple Git-157)`).
- **GitLab panel & babysitting (R3b `4bf2c9d`, `7574d53`, `c9f3b17`):** Excerpts are keyed by `JobKey(instance, projectPath, jobID)` and bounded to 32; `MergeRequestPanelView` reads both `excerpt` and `isLoadingExcerpt` through `JobKey`; server-supplied `Retry-After`, `duration`, and `expiresAt` are validated/clamped before integer conversion; wake retries and interpolated GitLab fields are redacted fail-closed.
- **Shared Chrome & secrets/egress (R3c `f418a50`..`77542bd`, `4c8c5c5`):** `SecretManager.applyEnvironment` properly settles superseded callers and cleans up stranded waiters on `releaseEnvironment`; `mutate` commits identical ledger-derived counts to SQLite and memory; `EgressProxy.serveRequests` and `beginDispatch` evaluate current scopes per request without breaking valid kept-alive traffic; `BrowseMCPClient` pairs `beginSend`/`endSend` on all paths, resumes continuations when cancelled before registration, and safely ignores non-integral/out-of-range JSON-RPC IDs (`Int(exactly:)`).
- **Plugin & Dockerfile handling (R3a `9b504d3`, `81574a2`):** `sessionCheckout` ([Plugin/src/project.ts:318–341](../../Plugin/src/project.ts#L318-L341)) allows user-layout symlinks above checkouts (including macOS `/var`) while refusing symlinks inside checkouts or into the middle of another checkout; `DockerfileBases.trimContinuation` and `ImageBuildNetwork.instrument` match BuildKit's escaped-escape rule cleanly.
