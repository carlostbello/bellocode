# BelloCode 1.0 release-readiness review

**Hold the owner handoff.** The arm64 release app assembled and passed strict local signature verification. The bundle identifies itself as **0.1.0 (549)** with opencode **2.3.2**. Four findings can cross the host or hidden-secret boundary or destroy the ordinary recovery path for uncommitted work. A separate certificate defect affects normal HTTPS after relaunch. All 70 selected tests passed.

Reviewed `59fd67c` on 2026-11-18 against the owner's decisions in `docs/PLAN.md`, section 0. **35 findings — 4 critical, 27 major, 4 minor.** R01–R10 are the top ten in release-fix order. Critical means potential disclosure of a protected value, loss of host confinement, or loss of unrecoverable user work. Major means a broken primary workflow, conditional isolation failure, or material reliability risk. R35 carries forward an unresolved prior finding. The failure scenarios below come from tracing production code unless the entry identifies an observed result.

## Critical

**R01 · Host Docker commands can escape the filtered endpoint.** In host Docker mode, the validator can accept a leading global option and return before checking the remaining arguments. Both command and MCP stdio paths then pass the entire argument vector to the host CLI. An agent command can select an unintended daemon or perform host-side file operations that the helper claims to forbid. Parse the complete supported grammar, reject unconsumed arguments and independently confine the host client to the approved endpoint and paths. `Sources/ContainerKit/Workspace/HostDockerCommand.swift:120`, `Sources/bellocode-exec/main.swift:113`, `Sources/bellocode-exec/main.swift:136`.

**R02 · The egress proxy can return a hidden credential in an HTTP response.** At a bound destination, the filter checks headers and body but the proxy forwards the original status line. A service that reflects a submitted value into response diagnostics can expose it to the calling process. An unsupported encoding can also be copied into the refusal and audit, and an unsolicited protocol upgrade leaves the inspected path entirely. Construct status lines and diagnostic messages locally, and allow upgrades only for a negotiated, unbound connection. Include every client-visible field and audit detail in redaction coverage. `Sources/SecretKit/EgressProxy.swift:659`, `Sources/SecretKit/EgressProxy.swift:705`, `Sources/SecretKit/EgressProxy.swift:718`, `Sources/SecretKit/ResponseFilter.swift:142`.

**R03 · A legacy command approval can receive a newly protected value.** An outstanding command reference or approval names the Keychain account. If the owner changes a commands-only secret to Brokered and rotates it, executing that previously requested command reads the *replacement* value with no current-mode or revocation check. An existing Always approval can also apply to a still-valid old reference. Bind references and approvals to a policy revision, invalidate them on protection changes, and reauthorize immediately before reading the value. `Sources/Engine/Extras/ExtrasHub.swift:699`, `Sources/Engine/Extras/ExtrasHub.swift:728`, `Sources/Engine/Extras/ExtrasHub.swift:750`, `Sources/Engine/Secrets/SecretManager.swift:250`, `Sources/Engine/Secrets/SecretManager.swift:269`.

**R04 · Failed worktree handoff can discard the stash needed for recovery.** If an editor recreates an untracked file while a handoff fails, restoring the stash to the source can fail. Rollback still attempts to drop the stash, and can force-remove the destination before verifying the source. Stash-and-switch repeats the unchecked apply/drop. Separate reads of the shared stash tip or index also let concurrent worktree operations select the wrong entry. Keep an operation-specific recovery ref and the destination until restoration is verified. Report unresolved paths and the recovery ref on any failure. `Sources/Engine/Git/WorktreeLifecycle.swift:55`, `Sources/Engine/Git/WorktreeLifecycle.swift:73`, `Sources/Engine/Git/GitRepositoryModel+Parity.swift:137`, `Sources/Engine/Git/GitWorkflows.swift:192`, `Sources/Engine/Git/GitWorkflows.swift:205`.

## Major

**R05 · Relaunch breaks the certificate chain for inspected HTTPS.** The first run creates a CA whose subject includes the Mac's name. Restore loads its certificate and private key with a generic common name. New leaf certificates then name that generic issuer while clients trust the original root. The default egress path can therefore fail TLS validation for workspace package downloads and shared Chrome after quitting and reopening BelloCode. Derive the issuer from the persisted certificate, verify its public key matches, and evaluate trust in a fresh leaf *after* restore. The existing restore test checks the root fingerprint. `Sources/Engine/Secrets/SecretManager.swift:498`, `Sources/SecretKit/CertificateAuthority.swift:114`, `Sources/SecretKit/CertificateAuthority.swift:187`, `Tests/SecretKitTests/ScannerTests.swift:134`.

**R06 · The handoff build has no installability check for the owner's Mac.** The ordinary target defaults to debug and ad-hoc signing. Even with release selected, the script ends at local integrity verification. A quarantined copy delivered to a second Mac can be refused before the app displays onboarding. The temporary release bundle passed that local check here. Provide an explicit release target that enforces the intended enterprise signing and distribution method. For Developer ID delivery, notarize and staple the artifact, then assess and open a transferred copy on a clean supported Mac. `Makefile:2`, `Makefile:22`, `Scripts/make-app.sh:25`, `Scripts/make-app.sh:215`, `Scripts/make-app.sh:224`.

**R07 · Browser startup can delete someone else's Docker container.** Chrome recreation stops and force-removes an existing same-name container regardless of its owner. A same-name profile volume is adopted, then can be deleted by Clear Site Data. The egress gateway also force-removes same-name containers. A collision with a manual setup or another installation can destroy its writable layer or profile. Persist resource IDs, verify installation and role labels before adoption or removal, and surface collisions with a non-destructive recovery action. `Sources/Engine/SharedBrowser/DockerBrowserRuntime.swift:84`, `Sources/Engine/SharedBrowser/DockerBrowserRuntime.swift:90`, `Sources/Engine/SharedBrowser/DockerBrowserRuntime.swift:112`, `Sources/ContainerKit/Network/EgressGateway.swift:134`, `Sources/ContainerKit/Network/EgressGateway.swift:208`.

**R08 · Project image code runs inside the trusted egress gateway.** The gateway takes the workspace image, runs its shell and interpreter, receives the scope's relay credential, and joins the outbound bridge. A repository-built image therefore controls code on both sides of the network boundary. Even a benign minimal image with neither supported interpreter blocks workspace startup. Ship a separate, pinned relay image or executable with a verified runtime, and keep the credential and bridge exclusive to it. `Sources/Engine/Secrets/SecretManager.swift:579`, `Sources/ContainerKit/Network/EgressGateway.swift:138`, `Sources/ContainerKit/Network/EgressGateway.swift:167`, `Sources/ContainerKit/Network/EgressGateway.swift:175`.

**R09 · Unreadable policy can turn a hidden or revoked secret into a legacy command secret.** Reload drops individual decode failures and treats a failed metadata query as an empty list. A surviving legacy label is then adopted and its policy row replaced with unconfirmed Visible mode. This loses revocation, scope and bindings and makes the account eligible for the approved-command path. Direct exposure through the thread environment still requires visible confirmation. Migrate positively identified legacy accounts transactionally and quarantine unreadable metadata with its original account ID intact. `Sources/Engine/Store/ProjectionStore+Secrets.swift:26`, `Sources/Engine/Store/ProjectionStore+Secrets.swift:35`, `Sources/Engine/Secrets/SecretManager.swift:187`, `Sources/Engine/Secrets/SecretManager+Agent.swift:62`, `Sources/Engine/Extras/ExtrasHub.swift:617`.

**R10 · Host Git can supply the PAT for a different GitLab installation.** Remote matching initially chooses the most specific installation path. The launch grant retains only host and port, Git omits its credential path, and the broker chooses the first installation on that origin. Two configured GitLab installations behind different prefixes of one HTTPS reverse proxy can receive each other's account credentials on fetch or push. Bind the grant to the resolved instance and remote path, retain the path in the helper exchange, and refuse an ambiguous match. `Sources/Engine/Git/GitCredentialBroker.swift:126`, `Sources/Engine/Git/GitRunner.swift:168`, `Sources/ContainerKit/HostGit/GitCredentialHelper.swift:182`, `Sources/Engine/Git/GitCredentialBroker.swift:224`.

**R11 · Auto mode can retain an allow when its session lookup fails.** The permission hook maps a failed session read to the ordinary “other” mode. A saved allow then survives without evaluation by Auto or a human. Treat unavailable mode as unknown, preserve denials and require a decision for any proposed allow. Exercise a failed lookup in a session with an existing grant. `Plugin/server.ts:345`, `Plugin/server.ts:364`, `Plugin/src/auto.ts:32`.

**R12 · Brokered use limits do not count against the binding.** The rewriter checks a counter keyed by binding ID. The HTTP tool records successful uses under a generic broker counter. Even sequential requests can exceed a one-use binding, and post-response accounting leaves simultaneous requests or lost responses unaccounted for. Reserve each binding use durably before dispatch across both proxy and broker, including redirect hops. `Sources/SecretKit/RequestRewriter.swift:233`, `Sources/SecretKit/SecretBroker.swift:146`, `Sources/Engine/Secrets/SecretManager+Agent.swift:115`, `Sources/Engine/Secrets/SecretManager.swift:447`.

**R13 · Narrowing secret scope leaves previous projects authorized.** Changing only scope retains existing grants. The proxy compares the grant's project to the gateway, and the visible-environment builder checks only mode and revocation. A project the owner has excluded can keep using the placeholder or, in Visible mode, receive the next rotated value. Invalidate grants outside the new scope, replace affected session environments, and check current scope on every substitution and delivery. `Sources/Engine/Secrets/SecretManager.swift:250`, `Sources/Engine/Secrets/SecretManager.swift:266`, `Sources/Engine/Secrets/SecretManager.swift:383`, `Sources/SecretKit/RequestRewriter.swift:222`.

**R14 · Registry and network policy cover the wrong parts of a local build.** A managed registry allowlist is applied to the locally generated output tag before the project build is selected. A permitted base image can therefore be unusable. Conversely, the filtered build route forwards the build body without enforcing its base-image sources and permits the ordinary bridge/default build network when workspace egress is enforced. Enforce source and network policy in the builder, including resolved bases and build stages, and exempt locally produced output names from pull policy. `Sources/Engine/Containers/EnvironmentService.swift:494`, `Sources/Engine/Containers/EnvironmentService.swift:518`, `Sources/Engine/Containers/DevContainers.swift:29`, `Sources/ContainerKit/DockerFilter/DockerFilterPolicy.swift:698`, `Sources/ContainerKit/DockerFilter/DockerFilterPolicy.swift:724`.

**R15 · Rebuild can pull a nonexistent tag and leave the workspace stale.** For a dev container, changing a file copied into the image leaves the tag unchanged because the hash includes only the context path, Dockerfile and build arguments/target. The existing image is reused. The Rebuild button calls pull on that local tag. Rebuild a source-defined image through its original build plan, let the builder invalidate changed inputs, and recreate the workspace only after a successful build. `Sources/ContainerKit/Workspace/DevContainer.swift:50`, `Sources/Engine/Containers/EnvironmentService.swift:544`, `Sources/Engine/Containers/EnvironmentService.swift:730`.

**R16 · Dev-container build paths are authorized by pathname prefix.** The parser checks standardized strings against the project prefix, then a later host CLI reads the Dockerfile and context by path. A linked or replaced directory under the project can resolve to another host folder when the build starts, sending files outside the selected project to the builder. Validate resolved objects and stage a bounded, project-confined context with no escaping links before invoking the builder. `Sources/ContainerKit/Workspace/DevContainer.swift:121`, `Sources/ContainerKit/Workspace/DevContainer.swift:195`, `Sources/ContainerKit/Workspace/ExecutionMode.swift:140`, `Sources/Engine/Containers/DevContainers.swift:39`.

**R17 · Upgrade can mark isolation settings migrated after a failed write.** Existing projects with container state are assigned Project container mode one at a time. The per-project save suppresses errors, then a separate write marks the entire migration complete. A failed row write followed by a successful marker write can move an existing project onto the shared workspace next launch. Write the settings and marker in one transaction, preserve unreadable rows for retry, and block affected commands until the saved mode is known. `Sources/Engine/Containers/ExecutionModes.swift:123`, `Sources/Engine/Containers/EnvironmentService.swift:385`.

**R18 · A development browser context can receive the installation's signing key in release.** The production locator prefers an environment-selected context over the signed bundle and searches the working directory when resources are missing. The builder supplies the Keychain-backed extension packing key to that context. A leftover development setting can give a different Dockerfile access to the production key. Use only verified bundled resources in production, fail visibly on missing files, and give development builds a separate disposable key. `Sources/BelloCodeApp/Launch/AppRuntime.swift:185`, `Sources/ContainerKit/Browser/BrowserImage.swift:78`, `Sources/ContainerKit/Browser/BrowserImage.swift:230`, `Sources/Engine/SharedBrowser/DockerBrowserRuntime.swift:62`.

**R19 · Allow Once for shared Chrome never advertises the tools it promises.** Approval stores the actual session ID, but the next directory-level tools listing asks for access using an empty session ID. With no permanent project grant, the agent still sees only Request Access after being told the browser is ready. Advertise the schema for a location with an eligible session, while enforcing the precise session and directory on every tool call. `Sources/Engine/SharedBrowser/SharedBrowserService.swift:313`, `Sources/Engine/SharedBrowser/SharedBrowserService.swift:349`, `Sources/Engine/SharedBrowser/SharedBrowserBroker.swift:66`, `Sources/Engine/SharedBrowser/SharedBrowserBroker.swift:107`.

**R20 · Restored browser approval cards can disappear without an answer.** The card is durable, but its session/directory tuple lives in a 16-entry memory map. After relaunch or eviction, answering removes the durable card and the handler silently returns. The thread receives neither access nor a denial. Restore the decision context from the durable request, resolve only after the decision is recorded, and give queue overflow a visible outcome. `Sources/Engine/SharedBrowser/SharedBrowserService.swift:324`, `Sources/Engine/SharedBrowser/SharedBrowserService.swift:342`, `Sources/Engine/Extras/ExtrasHub.swift:576`.

**R21 · Revoked Chrome access can return after relaunch.** The service removes the project from memory, suppresses failure to delete its stored grant, and refreshes tools. If SQLite refuses the write, restarting reloads the previous approval for a browser holding the owner's sign-ins. Persist the revocation or a durable pending-removal record, close admission immediately, and report completion only after deletion succeeds. `Sources/Engine/SharedBrowser/SharedBrowserService.swift:188`, `Sources/Engine/SharedBrowser/SharedBrowserService.swift:256`.

**R22 · Take Over permits already-dispatched agent input during human control.** The tab gate identifies active callers but leaves cancellation to its caller. The service discards that result and immediately marks the tab human-controlled. A queued browser-side input can still affect a signed-in page as the owner starts interacting. Close admission, cancel or drain affected operations and acknowledge control only when pending input has settled. This was a design requirement in the browser integration review. `Sources/Engine/SharedBrowser/BrowserTabGate.swift:168`, `Sources/Engine/SharedBrowser/SharedBrowserService.swift:483`, `Sources/Engine/SharedBrowser/SharedBrowserBroker.swift:177`.

**R23 · Chrome Stop can wait beyond its deadline or miss an in-progress start.** Cancelling the drain task group cannot resume its checked continuation, so the group still waits for the last browser call. A browse call may run for 660 seconds. Stop also returns during image preparation, and a failed readiness attempt can be marked stopped without stopping its container. Give the waiter cancellation-aware ownership, cancel and join startup, check generation before publishing Ready, and clean up the owned container on failure. `Sources/Engine/SharedBrowser/BrowserSupervisor.swift:181`, `Sources/Engine/SharedBrowser/BrowserSupervisor.swift:227`, `Sources/Engine/SharedBrowser/BrowserSupervisor.swift:287`, `Sources/Engine/SharedBrowser/BrowserSupervisor.swift:308`, `Sources/Engine/SharedBrowser/BrowseMCPClient.swift:75`.

**R24 · A brokered download can exhaust the app's memory.** URLSession buffers the entire body before BelloCode truncates it to 4 MiB. A legitimate large artifact from a bound GitLab or package service can terminate the app during a normal tool call. Stream into a capped buffer, cancel the transfer as soon as the limit is reached, and return a size refusal for the uninspected response. `Sources/SecretKit/SecretBroker.swift:195`.

**R25 · The Approved command choice cannot save a new secret.** The card clears its secure input before completion. The save converts this choice to Visible with confirmation set to false, which validation unconditionally rejects. The owner loses the entered value and cannot use the advertised commands-only option. Model commands-only delivery explicitly, save it without a visibility grant, and clear the field on successful save or deliberate cancellation. `Sources/AgentUI/Requests/AppRequestCards.swift:178`, `Sources/Engine/Secrets/SecretManager+Agent.swift:49`, `Sources/Engine/Secrets/SecretManager.swift:304`.

**R26 · Rewind can commit a conversation change after an incomplete file restore.** The plan silently cuts the diff at 5,000 paths. It also models target files as bytes, losing the target tree entry's type and executable bit. An ordinary deleted executable or symlink can be recreated as a regular file with the wrong mode, or files beyond the cap can stay at the later revision while the conversation is permanently rewound. Require a complete plan before committing the conversation, carry Git entry type/mode, and reject unsupported entries or limits explicitly. `Sources/Engine/Git/GitCheckpoints.swift:82`, `Sources/Engine/Git/WorkingCopy.swift:93`, `Sources/Engine/Git/WorkingCopy.swift:145`, `Sources/Engine/Presentation/Engine+GitParity.swift:91`.

**R27 · A repository can extend the host Git sandbox into another repository's metadata.** Writable roots include discovered Git directories if their canonical path contains a component named `.git`. A stale linked-worktree pointer copied from another checkout can consequently authorize writes to the other checkout's index or refs while the owner believes an operation affects only the selected project. Verify the worktree back-reference and approved common directory, and refuse unregistered external Git metadata before granting write access. `Sources/ContainerKit/HostGit/HostGit.swift:82`, `Sources/ContainerKit/HostGit/HostGit.swift:204`, `Sources/ContainerKit/HostGit/HostGit.swift:221`, `Sources/ContainerKit/HostGit/HostGit.swift:237`.

**R28 · Unsent attachments disappear when a draft is restored.** Existing-thread and new-thread composer hosts keep the rich draft in memory and persist only its text. After relaunch, the text returns while a staged screenshot, file or context pill can be gone. Persist a versioned structured draft and its attachment references, retain referenced files during startup cleanup, and restore legacy text drafts. This affects work composed *before* Send, distinct from the repaired pending-send outbox. `Sources/ComposerKit/Host/ThreadModelComposerHost.swift:119`, `Sources/BelloCodeApp/Content/ComposerSurface.swift:393`, `Sources/BelloCodeApp/Launch/AppDelegate.swift:59`.

**R29 · The packaged Intel app cannot build the native shared browser image as configured.** The app's assembly script supports x86_64, but the browser Dockerfile fetches an arm64 browse binary and validates architecture-specific Chromium packages with one set of hashes. A native amd64 Rancher VM can fail the build or be unable to execute the helper. Select binaries and checksums by target architecture and gate each advertised platform, or detect unsupported browser architecture before the long image build. `Scripts/make-app.sh:41`, `Containers/browser/Dockerfile:21`, `Containers/browser/Dockerfile:44`, `Sources/ContainerKit/Browser/BrowserImage.swift:230`.

**R30 · Disabling an MCP server can leave its tools available.** When the owner disables a registered remote server, sync suppresses a failed removal and clears the local registration anyway. If opencode rejected the request while still connected, it can continue serving the endpoint with the configured headers until a later reconciliation succeeds. Retain a pending removal, block use during the discrepancy, retry, and show completion only when the server confirms disconnection. `Sources/Engine/Containers/MCPServers.swift:64`, `Sources/Engine/Containers/MCPServers.swift:69`, `Sources/Engine/Containers/MCPServers.swift:86`, `Sources/OpenCodeKit/HTTP/OpenCodeClient+Isolation.swift:187`.

**R31 · Cancelling a dev-container build leaves the Docker child running.** The project task awaits a continuation resumed only by process termination. A stuck build has no deadline or cancellation handler, and changing projects or stopping the service can leave the build using Rancher resources or publishing its tag after cancellation. Own the process and pipes in the build task, terminate and reap on cancellation or deadline, and publish the result only for the current project generation. `Sources/Engine/Containers/DevContainers.swift:38`, `Sources/Engine/Containers/DevContainers.swift:54`, `Sources/Engine/Containers/DevContainers.swift:74`.

## Minor

**R32 · Missing-image recovery points to the wrong field in the default mode.** Choose Image opens Project Environment when a directory is supplied. Its editable project image field has no effect on the shared workspace, which uses only the global default. There is a note explaining this, but following the primary action can leave all commands blocked. Open and focus the effective global field in shared mode and disable irrelevant project controls. `Sources/Engine/Containers/EnvironmentModels.swift:300`, `Sources/Engine/Containers/EnvironmentService.swift:493`, `Sources/BelloCodeApp/Settings/ContainerSettings.swift:97`, `Sources/BelloCodeApp/Settings/ContainerSettings.swift:939`.

**R33 · Onboarding promises free models even with an empty catalog.** With no provider configured, Skip advertises immediate access even when model discovery returned nothing or has timed out. The project also records shared free-model quota failures on this pin. Show catalog loading, unavailable and eligible-model states explicitly, keep provider connection reachable, and preserve the first draft on provider failure. `Sources/AgentUI/Accounts/AccountsViews.swift:208`, `Sources/AgentUI/Accounts/AccountsViews.swift:227`, `Sources/BelloCodeApp/Launch/AppDelegate.swift:282`, `docs/features/opencode-upgrades.md:56`.

**R34 · The candidate reports version 0.1.0.** Both the assembled release plist and the About path use the checked-in version. An owner reporting a problem with the 1.0 handoff will see 0.1.0 (549). Set the intended release version and assert the expected marketing version and build number against the final artifact. `VERSION:1`, `Scripts/make-app.sh:27`, `Sources/BelloCodeApp/Settings/AboutInfo.swift:9`.

**R35 · Routine account refresh still requests a secret-bearing response.** This is deep-review-1 S8, still present. App launch initiates refresh, which asks for the credential list to populate account summaries. The decoder retains summary fields, but the response brings provider values into the app's HTTP buffer on an ordinary launch. Use a summary-only source or extend the pinned contract and leave account values with the server. This finding was checked by source inspection only. `Sources/BelloCodeApp/Launch/AppDelegate.swift:60`, `Sources/Engine/Auth/AuthService.swift:263`, `Sources/OpenCodeKit/HTTP/OpenCodeClient+Integrations.swift:107`, `docs/reviews/deep-review-1.md:211`.

## Acceptance limits and follow-up

Applied the UX checklist in `docs/research/03-ux-patterns.md` section E to the source and available fixtures. Evidence covers startup sequencing, missing/stopped runtime states, partial sync, approval persistence and draft restoration paths. Keyboard-only operation, IME, VoiceOver, multiple windows/monitors, 30 active sessions, streaming selection, measured feedback latency and visual confirmation of a nonblank pane still need an attended pass.

The full test suite, a transferred/quarantined install, macOS 15, Intel, a real prior installation, live provider authentication, GitLab fetch/push, live Rancher with missing images, and real shared-Chrome startup/quit were unverified. No live credentials, user Chrome profile, Rancher settings or personal opencode data were accessed. The release decision should be revisited after targeted fixes, a clean-Mac install through the intended distribution channel, and a second launch with HTTPS, a disposable worktree, and browser approval/revocation exercised end to end.
